Private by design. Images and decoded QR text are processed entirely in this browser tab. Nothing is uploaded, no analytics, no network calls — except the optional jsQR decoder from a CDN if your browser lacks the native BarcodeDetector API.
Requires a secure context. Camera access only works over https:// or http://localhost (a plain http:// LAN address is blocked). Opening this file straight from disk (file://) keeps the UI working and the camera usually still runs in Chrome, but PWA install and service workers need an https:// or localhost origin.
